# ClipForge AI

AI 기반 숏폼 영상 스크립트 및 자동 편집 도구

## 프로젝트 소개
ClipForge AI는 사용자가 영상 주제를 입력하면 AI가 숏폼용 스크립트를 자동 생성하고, 자막·컷 편집·재생 장면 구성까지 함께 추천해주는 웹 서비스입니다. 개인 크리에이터, 마케터, 교육 콘텐츠 제작자들이 빠르게 고품질의 숏폼 영상을 제작할 수 있도록 돕는 것을 목표로 합니다.

## 배경 및 문제 정의
숏폼 콘텐츠는 조회수와 도달률이 높지만, 제작 과정은 매우 번거롭습니다. 대부분의 사용자는 다음 단계를 모두 수동으로 처리해야 합니다.

- 아이디어를 떠올리는 단계
- 스크립트 작성
- 자막 생성
- 영상 편집
- 업로드용 문구와 해시태그 구성

특히 개인 크리에이터나 소상공인은 제작 시간을 줄이기 어렵고, 영상 퀄리티를 유지하기에도 많은 노력이 필요합니다. 이 프로젝트는 AI를 활용해 콘텐츠 제작을 자동화하고, 누구나 빠르게 숏폼 영상을 제작할 수 있도록 지원합니다.

## 핵심 기능

### 1. AI 스크립트 자동 생성
- 사용자 입력 기반 숏폼 스크립트 생성
- 주제, 타깃, 톤(유머/설명형/전문형)을 반영한 문장 구성
- Hook 문구, 핵심 메시지, CTA 자동 생성

### 2. 자동 편집 및 자막 생성
- 스크립트에 맞춘 컷 분할 및 편집 시나리오 생성
- 자막 자동 삽입
- 영상 길이와 타이밍 최적화
- B-roll 이미지/영상 추천 기능

### 3. 업로드 최적화 및 분석 추천
- 제목, 설명, 해시태그 자동 생성
- 업로드 전 시청자 반응을 고려한 콘텐츠 점검
- 주제별 최적 포맷 추천

## 주요 목표
- 숏폼 영상 제작 시간을 단축한다.
- 비기술자도 손쉽게 고품질 콘텐츠를 생성할 수 있게 한다.
- 콘텐츠 제작의 반복 작업을 자동화한다.
- 소규모 창작자와 교육/마케팅 분야에서 실사용성을 높인다.

## DORA Metrics 자동 수집
이 프로젝트는 GitHub Actions를 통해 DORA 4대 지표를 자동으로 수집하고, 배포 성과를 시각적으로 확인할 수 있도록 구성합니다. 이를 통해 개발 프로세스의 속도와 안정성을 정량적으로 점검할 수 있으며, AI 기반 콘텐츠 제작 프로젝트에서도 운영 지표를 함께 관리할 수 있습니다.

- Lead Time for Changes
- Deployment Frequency
- MTTR
- Change Failure Rate

### 포함 파일
- `.github/workflows/dora-metrics.yml`
- `github/actions-scripts/compute_dora.py`
- `dashboard/index.html`
- `tools/generate_dashboard_snapshot.py`

### 샘플 대시보드
![DORA Dashboard sample](assets/dora_dashboard_sample.svg)

### 사용 방법
1. GitHub Actions에서 `DORA Metrics Collector` 워크플로우를 실행합니다.
2. 실행 후 Artifacts에서 `metrics.json`을 다운로드합니다.
3. 로컬에서 `dashboard/index.html`을 브라우저로 열어 대시보드를 확인합니다.
4. `python3 tools/generate_dashboard_snapshot.py`를 실행하면 SVG 스냅샷을 다시 생성할 수 있습니다.

이 자동화 흐름은 최근 30일 동안의 배포 이력, 배포 상태, PR 병합 기록을 기반으로 지표를 계산하고, 결과를 JSON 형태로 저장한 뒤 대시보드와 SVG 스냅샷으로 재사용할 수 있게 설계되었습니다. 특히 배포 빈도, 실패율, 복구 속도, 변경 반영 속도는 운영 품질을 판단하는 핵심 지표로 활용됩니다.
